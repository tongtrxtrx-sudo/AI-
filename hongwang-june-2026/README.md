## 配套文件怎么用

- data/示例CSV：三家各99行，01→02→03逐份导入；04是三家297行合导替代，不是第四家，不需要两种方法都做。
- data/空白CSV：本期六列99行结构，按实际项目和月份填写金额，不把原报表整张覆盖。
- data/Excel整理表：字段中文说明和待填/已填表，先另存UTF-8 CSV；内部销售准备表须照页面维护，没有Excel抵销导入入口。
- 需要2026年初BS、6月末BS、1—6月累计PL/CF及逐月PL/CF。不能只有6月单月、不能平均摊成假月度，不能倒挤现金流。
