## 二、Windows二进制兼容层与浏览器证据

Wine中实际执行生产原生EXE→包内Windows Python→Windows QEMU，覆盖中文与空格程序／数据路径，没有Linux可执行文件替代。使用的是**原配基础盘上的旧初始化私有调试快照**，并非最终空白基础盘新种子首装：

- 两轮启动至严格就绪分别455.005秒、538.125秒；两轮各11项HTTP检查通过，共22项，私有File元数据和内容SHA一致。
- 重复启动复用同一实例；两次正常停止及控制器退出分别14.955秒、14.570秒，退出码0；成功轮次未强制quit，相对backing和QCOW结构检查通过。
- 零参数GUI入口实际执行pythonw分支、复用已有控制器并退出0，未另建VM。该项只证明入口与复用，**未目视验证Windows浏览器或全新GUI冷启动**；主集成使用`--no-browser`。

浏览器交互另由Linux Chromium在调试客体完成：真实登录及首次向导，Entity、Consolidation Group、Budget Cycle和Close四路由到达且页面非空，本地资源加载成功，无JavaScript异常。不能把该记录写成Windows浏览器验收。

首次无维度站点补入Business Unit、Cost Center、Department并同步初始架构，已有维度保留；这是本次新增部署桥接，不插入集团、实体、科目或财务演示明细。首次核心建站中断恢复只限有本机登记的未完成阶段，保留旧资料；已就绪业务库不自动重置。Cube采用便携单实例内存缓存／队列配置，不据此推定多实例、高可用或生产容量通过。

Linux宿主文件系统／协议套件18项通过，覆盖种子、锁、基础盘与业务盘保护、控制页鉴权、503启动状态和QMP身份；其中下载异常分支使用受控传输响应，QMP协议使用独立测试服务。完整公网下载与真实客体正常关机由上文另行举证。原始Konsolidat 618文件、Konsol 897文件保全检查无新增、丢失或修改；部署适配独立保存。
