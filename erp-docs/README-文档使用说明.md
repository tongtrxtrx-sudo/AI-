## 从哪开始

先读产品说明的“鸿旺小合并”和NC准备清单，再按用户手册导入。首次可用内置完整虚构样例熟悉操作；使用自己的NC文件时，配置真实账簿、科目与内部客商映射，并准备年初余额及1月至测试月完整已记账凭证。内部应收应付期初非零，需客商层辅助余额。

本位币账使用NC“本币借方金额/本币贷方金额”；不把原币、集团本币和全局本币重复入账。共同关联号、对方或金额不符时先处理差异，不自动补差。文件模式不等于已连NC在线API，本系统也不向NC写回凭证。
