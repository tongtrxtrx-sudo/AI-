# 天元 EPM Demo 独立验收报告

验收日期：2026-10-20（UTC）  
对象：杭州天元宠物用品有限公司 · 中文本机演示版  
结论：当前冻结代码与真实 HTTP 构建的 16 组验收场景全部通过；验收过程中代码未改变，三份测试报告对应同一份源清单。此结论覆盖本机 Demo 的已列功能，不代表生产财务系统验收。

## 实测环境与可重复证据

- 服务：Python 3.12 标准库 HTTP 服务 + SQLite；各测试使用独立临时数据目录。
- 浏览器：真实 Chromium，使用 Playwright 访问 HTTP；没有以 file://、静态 HTML 注入或仅端口检查替代业务操作。
- 财务基准：收入 13000、净利润 1720、资产 9580、负债 4730、权益 4850、经营现金净流入 1450、期末现金 2050，默认三表全部勾稽通过。
- 范围测试：集团与制造子集团各 1 至 12 月，共 24 种组合；修改美元汇率后，后端美元收入按新汇率变化。
- 持久化：浏览器实际保存基础层金额 16123.45，刷新页面仍保留；整个后端安全退出并用同一数据目录启动新进程后仍保留。
- 财务变动：凭证草稿不影响净利润；选择经营现金流分类并审批费用／现金 10 后，净利润从 1720 变为 1710，旧确认与校验失效，重新运行三表校验仍通过。现金凭证未选择分类会拒绝。
- 期间隔离：先完成 8 月签核，再导入 9 月数据；8 月报表、说明、校验与签核对象全部保持原值。
- 权限和错误：直接向服务端发只读角色写请求被拒绝；四类错误 CSV 整批零写入；无会话、无 CSRF、跨来源请求被拒绝。
- 中文体验：20 项完整导航实际打开，普通英文界面文案检查通过；未出现邮箱登录、英语向导或 Frappe 后台。
- 数据位置：通过实际服务获取固定数据目录；浏览器点击打开目录，在当前 Linux 环境返回可复制路径说明；浏览器确认安全退出后实际后端进程停止。真实 Windows 资源管理器行为以 Windows 运行包专项验证为准。

## 仍需保留的功能边界

演示子法人和金额为虚构。固定 2026 年度；美元为展示换算；未报送 10 至 12 月沿用 9 月累计。CSV 现金流采用有明确说明的估算桥接，不能视作已完成真实现金流映射。预算成本费用比较基准固定，业务明细独立保存，不自动生成生产级三表预算。Demo 不含真实 ERP／Excel 插件接入、生产多用户认证、法定报表准则认证与互联网部署验收。

本报告测试的是当前 HTTP 应用。原生 Windows EXE、嵌入式运行环境与 Wine 的专项验证由 Windows 交付记录单独列示；本轮没有实体 Windows 10／11 硬件实测证据。旧 Frappe／QEMU 平台与其数据不在本次测试和修改范围内。
