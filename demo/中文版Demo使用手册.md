# 天元 EPM Demo 中文使用手册

公司：杭州天元宠物用品有限公司  
版本：中文本机演示版  
适用范围：集团财务合并、全面预算、经营分析的产品验证与研发演示。

## 产品与数据说明

这是按完整产品原型重建的独立中文 Demo，提供本机持久化演示业务操作。页面上标注“演示环境”，样例公司、报表、业务单据和金额用于演示，不能作为公司的正式财务账或监管申报依据。当前 Demo 与此前的 Frappe／Konsolidat 后台分别运行，不会自动读取旧平台数据。

## 安装与启动

1. 下载新的 Windows 运行压缩包，完整解压至可写文件夹。
2. 双击包内“天元EPM Demo.exe”。启动器会自动打开本机网页。
3. 运行时使用包内嵌入的 Python 环境，无需自行安装 Python、Docker、WSL 或 QEMU。
4. 新 Demo 不使用 Gmail 等邮箱登录，也不需要完成旧平台的英语初始化向导。

系统只监听本机地址 `127.0.0.1`，网页端口由启动器自动选择。再次双击启动器会打开已经运行的本机 Demo；请勿使用旧包中固定的 `18480` 地址。

关闭浏览器标签页不会停止服务。完成演示后，在“系统配置 → 本机环境工具”使用“安全退出”；再次启动会读取原来的已保存数据。

默认演示数据保存在 `%LOCALAPPDATA%\TianyuanEPMDemo`，主数据库为 `epm-demo.sqlite3`。可在“系统配置 → 本机环境工具”使用“打开数据目录”查看；Windows 会打开资源管理器，其他平台会显示位置说明。这与旧软件的 `SelfDevelopedEPM` 目录不同。备份时先安全退出，再完整复制新数据文件夹；只复制运行程序目录不等于备份业务数据。不要删除数据目录来解决普通启动问题。

首次运行只初始化演示样例。刷新页面、关闭浏览器或安全退出后再启动，都不应重置已保存的预算、报送批次、凭证和审计记录。

## 推荐演示路线

先查看集团驾驶舱与组织范围，再查看默认合并报表及抵销凭证；随后修改预算、保存并刷新验证，再完成提交、审批、锁定与调整版本；最后查看经营分析、关账检查与审计轨迹。

## 预算编制、审批与调整

1. 进入“预算编制与分摊”，在基础层等预算层上选择修改，输入金额后保存。金额非负，最多两位小数。
2. 刷新页面确认金额保留；也可安全退出、重新双击 EXE，再查看相同预算版本。
3. 进入“预算周期与审批”，依次提交、由集团财务负责人审批、锁定。锁定版本不能直接修改预算金额。
4. 如需演示另一方案，进入“版本与多情景”复制版本，填写不重复的名称，保存为独立草稿。
5. 如需调整锁定预算，进入“预算调整与滚动预测”，填写调整层级、增减金额及原因，提交后审批。系统产生独立调整版本，保留原版本金额；通过版本切换可比较两版。

预算业务明细为演示编制数据，不能视作已实现供应链订单、生产排程、工资、采购执行或真实支付。

## 报送 CSV 与错误处理

导入前先选择正确期间。使用 UTF-8 CSV，第一行必须严格为：

```csv
法人编码,期间,科目编码,借方余额,贷方余额
```

期间按 `2026-09` 填写，必须与当前选择月份一致；法人和科目必须已存在。每个法人导入一整套累计试算余额，借贷合计须相等；同一法人、同一科目不可重复。金额非负，最多两位小数，不允许同一科目同时填写借方和贷方正余额。

导入会替换该法人在当前期的整套余额，不是仅追加一笔差额。任意一行有错误时，整批拒绝，不会先写入正确行。根据中文错误中的行号修改文件后再试。导入为演示三表生成数据，现金流的自动估算口径见环境功能边界，不应直接用于正式财务报表。

## 凭证、校验与关账

1. 新建调整凭证，填写摘要、原因与至少两行分录。每行仅填写借方或贷方正金额，整张借贷金额必须相等。如果包含现金科目，必须选择“经营活动”“投资活动”或“筹资活动”现金流分类，否则拒绝保存；该分类会真实影响现金流量表。
2. 保存草稿后，由集团财务负责人审批；已审批凭证会实际影响对应期间的合并报表。
3. 确认法人报送，运行财务校验，保存内部交易核对说明、经营分析说明。
4. 前置条件均满足且校验仍有效时，由负责人执行集团签核。
5. 签核后的期间需要负责人填写原因重新开启，才可继续修改相关财务数据。数据发生变化时，旧校验及报送确认会失效，应按提示重新执行。

不同月份分别保存流程状态。切换到另一月份不能沿用原月份的签核。

## 演示角色与权限

默认使用集团财务负责人。法人会计可体验部分编制业务；负责人负责审批、签核和基础配置；审计只读只能查看。服务端也会拒绝只读角色的写入请求。

这里的角色切换是为了单机演示权限差异，不是公司正式多用户登录。不要把启动链接分享给不可信程序，也不要将本机演示服务映射到互联网。

## 常见问题

|现象|处理|
|---|---|
|仍进入英文 Frappe 页面|关闭旧地址，双击新包的“天元EPM Demo.exe”；新 Demo 不使用旧固定端口。|
|询问 Google 邮箱、登录密码或选择英语|当前打开的是旧平台；新 Demo 无需邮箱初始化。|
|提示数据版本已更新|另一个标签页修改了数据。刷新当前页面、确认最新金额后再保存。|
|提示预算已审批或锁定|复制为新版本，或走独立预算调整流程。|
|导入失败|按中文行号修复编码、月份、借贷平衡或重复科目，再重新导入。|
|无法签核|完成报送确认、当前有效校验、内部交易说明及经营说明；有数据变化时重新校验。|
|提示缺少文件|重新完整解压运行包，保持程序、内嵌环境、前端和后端目录结构。|
|浏览器关了但进程仍在|关闭标签页不等于安全退出。在“系统配置 → 本机环境工具”点击“安全退出”。|

## 功能边界

本机演示版用于产品体验与需求评审，存在以下明确边界：

- 主公司名称按需求展示；子法人、业务、科目余额、报表数字均为虚构样例，不代表杭州天元宠物用品有限公司的真实财务状况。
- 样例法人使用同一本位币人民币。美元是演示展示换算，不能等同于外币报表折算准则、交易日／平均／期末汇率区分或完整外币折算差额处理。
- 默认 1 至 9 月为演示累计趋势；尚未报送的 10 至 12 月沿用 9 月累计余额。实际导入只替换指定法人、指定月份，不自动生成之后月份的真实业务。
- CSV 只提供累计试算余额，未包含现金流明细。系统沿用样例期初现金与样例投资／筹资现金流，以期末现金变动倒算经营现金流，并标记为估算；不声称已经完成真实现金流项目映射。现金凭证按用户选择的经营、投资或筹资分类影响现金流。
- 合并结果基于当前样例范围、持股和已审批调整计算；不涵盖购买日估值、复杂交叉持股、多层少数股东、税务差异和完整中国会计准则适用性。
- 四层收入预算可以保存、分摊、审批锁定和形成独立调整版本。经营分析中的预算成本／费用比较基准为固定演示口径；生产、采购、存货、人工、费用、资本、现金等业务预算明细独立保存，不会自动构成完整三表预算，也不构成采购或生产执行。
- 真实 ERP 连接和 Excel 实时插件不在本 Demo 范围内。CSV 导入是本轮可用的业务数据入口。
- 本轮角色切换用于演示服务端授权差异；生产级多用户身份管理、企业单点登录、网络部署、审计合规和安全认证仍需专项研发验收。
