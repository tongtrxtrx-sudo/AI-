# 杭州天元宠物用品有限公司 · EPM 中文文档三件套

本套文档对应已交付的 `20261020-cn-demo1` 中文本机演示版。三份文件均为可编辑的原生 Word `.docx`，附同内容 PDF。三份 PDF 共 65 页；Word/WPS 的实际页数可能随字体与排版设置变化。

| 文档 | 附带 PDF 页数 | 适用读者和内容 |
| --- | --- | --- |
| 01_系统研发与交互说明书.docx | 21 | 研发、测试和实施人员；架构、研发方法、源码、前后端交互、接口字段、SQLite、财务及预算规则、构建与发布。 |
| 02_产品说明书_含演示案例.docx | 20 | 产品及财务负责人；产品地图、20 项菜单、模块联动、8 个可照做的演示案例与结果。 |
| 03_用户操作手册.docx | 24 | 财务、预算和经营分析使用者；启动、字段填写、导入、凭证、审批、签核、备份与排错。 |

初次体验可先读用户手册的上手步骤，再按产品说明书案例演示；开发接手时再阅读系统研发与交互说明书。Word 内的阅读导航可点击跳转，标题可在 Word/WPS 导航窗格中使用。

## 文件夹内容

- 根目录：三份 Word 和本文。
- `PDF`：三份便于阅读、打印的同内容 PDF。
- `演示案例附件`：产品说明书案例四使用的三份 UTF-8 CSV。
- `可编辑原稿`：Markdown 原稿、图示、真实浏览器截图及文档生成脚本，仅供研发人员维护文档。
- `核验记录`：文档结构/版面核验、无凭据的案例金额核验及 CSV 附件实测结果。
- `SHA256SUMS.txt`：包内文件的完整性校验。

## 案例四 CSV 怎么用

在独立的全新案例环境、集团合并范围、2026 年 09 期、人民币视图下，进入“试算平衡报送”导入。先核对产品说明书的前置条件。

1. `案例四_01_完整平衡样例.csv`：63 行完整样例；导入后收入 13,000、净利润 1,720 万元。
2. `案例四_02_制造销售收款增加100万元.csv`：在完整样例上增加制造法人现金与收入各 100 万元；导入后集团收入 13,100、净利润 1,820、资产 9,680、现金 2,150、经营现金净额 1,550 万元。
3. `案例四_03_错误样例_借贷不平衡.csv`：专门用于错误验证。制造法人借贷差额 1 万元，应整批拒绝，之前的金额与数据版本保持不变。

这些结果已用随本包提供的实际 CSV 在隔离 HTTP 环境验证。第三份不能用于正常报送。切换案例数据目录前先安全退出，一次保留一套演示环境；不通过删除数据库恢复样例。

运行软件另行下载，文档 ZIP 不包含 EXE。软件包为 `TianyuanEPMDemo-Windows-x64.zip`，SHA-256 为：

```text

```

这是根据完整原型实现的独立中文 Demo。文档依据其实际实现编写，并标明演示计算口径及后续研发建议。主公司名称由用户提供，子法人、人员、交易和全部金额均为虚构样例；旧 Konsolidat 平台账套不会自动迁入。会计年度固定 2026；初始实际截至 9 期，未独立导入时后续期沿用 9 期累计。正式生产能力、会计准则、真实 ERP 接口和组织身份隔离需继续研发及验收。

## 文档维护

普通使用者直接打开 Word/PDF，无需安装 Python。只有重新生成文档的研发人员需要 Python 及 `requirements-docs.txt` 中的工具；先运行 `render_documents.py` 生成 Word，再使用支持的 Office/LibreOffice 转出 PDF。软件实际源码和原生 EXE 构建说明在软件运行包中，不能用文档生成脚本代替软件构建。
