# 天元EPM：Excel资料准备与导入

适用软件：ERP-20261021。补充资料版本：IMPORT-KIT-20261021-D1.0。本包不更新软件，原EXE和原四册完整文档继续适用。

1. 先打开《天元EPM_Excel模板填写与导入操作说明.docx》，里面有16张真实功能点截图。
2. 第一次练习用“已填示例”；填写自己的资料用“Excel模板”。不要把示例和真实数据混导。
3. 01科目、02期初、03 NC48列、06通用替代模板可直接导入。打开首表“导入数据”，从A2开始按列粘贴值，保留第一行表头；空白文件还没有业务数据，直接上传会被正常拒绝。
4. 03与06对同一业务只能选一种。NC03使用页面下方“导入NC6.5凭证”，通用06用上方③“完整已记账凭证→选择文件并导入”。
5. 04是“维护NC6.5适配”的页面照填资料；05是现金行分类核对与补注清单。两份都没有独立Excel上传入口。
6. 全七法人示例先分别重开鸿旺和海外及祖先，再回集团范围导入/生成全部；仅三家鸿旺资料可在鸿旺范围做小合并。负责人明确停用本层预置示例交易，避免双抵销，保留投资权益和用户真实手工事项。
7. 导入成功只是保存资料：仍需生成法人三表→扫描匹配→处理差异→生成抵销草稿→负责人审批→鸿旺计算签核→海外/集团逐层上卷。

本币借贷以法人本位币元入账，两位；报表为万元六位。NC原币、集团/全局币、单价、数量和汇率按原值保留，不重复入账，不统一截断精度。USD期初留存收益的人民币历史额是特例：02“期初人民币留存收益”填写人民币元，以该列字段说明为准。

已填示例：84条映射、14行期初、48行NC分录；06为同业务替代。假设1—8月无发生，分录集中9月；真实数据仍须年初至测试月完整已记账凭证。鸿旺3项准确匹配后收入1400/净利450/资产650，集团收入2650/净利770/资产2370/CTA74/现金汇率影响90，单位人民币万元。全部业务数字为虚构演示，不是企业实际报表。

金额差异不自动补平。核实为识别信息缺失可在有效原行补注；金额错误需回ERP更正，停用旧批后重导，保留历史来源。

本包包含Word、同源PDF、6模板、4已填Excel、NC示例配置参照、16原图、填写原稿及实际验收记录。NC在线同步尚未配置，本包使用文件导入。
