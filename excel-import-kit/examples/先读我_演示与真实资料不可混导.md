# 已填示例的使用范围

全部为虚构业务，只用于ERP-20261021新测试账套。01为84行映射，02为14行期初，03为NC48列48行凭证；06是同一交易集的通用格式替代，03与06只能二选一，不能双重入账。

04 JSON只是逐项照页面维护的配置参照，没有JSON导入按钮。模板中的HW_BOOK/NC-HW等不是你们真实NC编码。

顺序：重开相关层→维护NC适配（用03时）→导入01→导入02→导入03或06→生成七家法人→扫描鸿旺→确认停用本层预置交易抵销→准确项生成草稿并批审→鸿旺签核→海外签核→集团本层扫描/转换/审批→集团签核。

鸿旺本文件案例内部销售已结80+未结20，应收应付20；准确匹配3项，收入1400/净利450/资产650万元。集团本层1项50万元销售，集团收入2650/净利770/资产2370/CTA74/现金FX90万元。不要与产品内置396行/18+9匹配样例混用。

真实资料粘贴到Excel模板目录的空模板，从A2开始粘贴值，完整原凭证借贷平衡，金额元、日期2026。不得把表外示例合计或说明作为业务分录导入。
